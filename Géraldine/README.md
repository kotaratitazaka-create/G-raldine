# Portfolio de Géraldine

Portfolio personnel de Ouakondja Géraldine Zoungoula Kokouendo, construit en HTML/CSS.

## Structure du projet

- `index.html` : page principale du portfolio
- `src/` : ressources visuelles et assets
- `server.js` : serveur local pour servir le site
- `package.json` : configuration du projet Node

## Prérequis

- Node.js installé sur votre machine

## Lancer le projet localement

```bash
npm install
npm start
```

Ensuite, ouvrez votre navigateur sur :

```text
http://localhost:3000
```

## Déploiement

Ce projet peut être déployé sur des plateformes statiques ou Node-friendly comme :

- Netlify
- Vercel
- GitHub Pages
- Bolt

## Notes

Le site est conçu pour une mise en ligne simple, sans dépendances lourdes.
